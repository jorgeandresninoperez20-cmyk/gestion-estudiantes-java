# Sistema de Gestión de Estudiantes (Java)
Aplicación de consola para registrar estudiantes, listar, buscar por matrícula y calcular el promedio general.

## Requisitos
JDK 8 o posterior. Funciona en VS Code con Extension Pack for Java, IntelliJ IDEA, Eclipse o NetBeans.

## Archivos
- `Estudiante.java`: atributos privados, constructor y métodos.
- `GestionEstudiantes.java`: menú e interacción.
- `Documentacion_Actividad_Formativa_2.docx`: informe académico.
- `Presentacion_Actividad_Formativa_2.pptx`: presentación.

## Ejecutar
En una terminal abierta en la carpeta que contiene los archivos Java:
```
javac Estudiante.java GestionEstudiantes.java
java GestionEstudiantes
```
La calificación aprobatoria se define como 70. Los datos solo permanecen durante la ejecución.
